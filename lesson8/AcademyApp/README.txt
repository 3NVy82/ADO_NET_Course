1. Выполни Sql/CreateCollegeDB.sql в SSMS (создаст CollegeDB и 5 таблиц).
2. Открой AcademyApp.csproj в Visual Studio (NuGet восстановит Microsoft.Data.SqlClient).
3. При необходимости поменяй connectionString в Program.cs.
4. Запусти проект (F5).

Если у тебя уже есть проект AcademyApp (.NET Framework): скопируй папки Models и Data
и файл Program.cs, поставь NuGet-пакет Microsoft.Data.SqlClient.
