1. Открой AcademyApp.csproj в Visual Studio (Файл -> Открыть -> Проект или решение).
2. При необходимости поменяй connectionString в Program.cs.
3. Запусти проект (F5). База CollegeDB, таблицы и тестовые данные создадутся автоматически.
   (Скрипт Sql/CreateCollegeDB.sql делает то же самое вручную и нужен только для справки.)

NuGet-пакеты: Microsoft.Data.SqlClient, Dapper.
