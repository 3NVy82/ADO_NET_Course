ADO.NET Course - Урок 3 (SqlConnection -> SqlCommand -> SqlDataReader)

1. Откройте AdoNetLesson3.csproj в Visual Studio (File -> Open -> Project).
2. NuGet-пакет System.Data.SqlClient подтянется автоматически при сборке
   (или: Проект -> Управление пакетами NuGet).
3. В Program.cs замените Server=... на имя вашего сервера.
4. Запустите (F5).
